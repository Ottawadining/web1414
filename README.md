# Rotten Critics

Satire and opinion about Canadian restaurant criticism. [rottencritics.com](https://rottencritics.com)

Static Next.js site (exported to GitHub Pages) with Supabase for voting, comments, nominations and moderation. Rules are enforced in the database with Row Level Security; see `supabase/migrations/`.

```bash
npm install
npm run dev
```
